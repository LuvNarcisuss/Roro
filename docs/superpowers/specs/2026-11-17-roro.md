The November 23, 2026 Swift migration supersedes all earlier implementation and build instructions in this record. The product and interaction requirements still apply. Current build instructions are in README.md.

Approved in conversation on November 17, 2026. The owner selected casual everyday photography and authorized construction from the proposed warm album design.

## Product
The owner subsequently expanded navigation to Home / Topics / Shorts / Chats / Me. This is the current structure; see 2026-11-17-shorts-design.md for the local video extension.

Home uses a warm-white single-column photo feed, Discover/Following, a compact everyday topic and a create action. Chats offers Recent, Friends and Archived lists, member search and locally saved conversation entries. Me contains the user's moments, saved inspiration and drafts. Detail supports full images, personal likes/saves and private notes. Topic pages group photos. Search filters captions and topics. Creation imports up to three photos with an optional caption/topic. Settings provides profile editing, exact agreement hyperlinks, local data controls and a StoreKit wallet.

## Design
Background #FAF8F5, ink #292724, secondary #716B65, accent #B95138, soft #F3E6DB. Nunito typography. Rounded raster icons, 44-point targets, generous single-column photographs, 16-point image corners, safe-area-aware navigation and reduced-motion support.

## Architecture and boundaries
React Native 0.88.1 with React 19.3.0 hosts all product screens as bundled React/TypeScript H5. iOS 16 exceeds the official RN minimum of 15.1. Native modules extract a validated ZIP, persist state atomically, import photographs with PHPicker and process StoreKit 1. No Supabase. Assets stay in root Assets. Agreements use the supplied Google Docs URLs. No asset or payment private keys.

Local-first is explicitly approved. Saving a moment is local and never claims public upload. The owner subsequently authorized fictional local community personas and engagement, using licensed Pexels videos and existing licensed photos. Original source creators remain separately credited. Author and topic totals are derived from work records; comment counts come from comment arrays. This supersedes the initial no-seeded-engagement decision. Private notes never claim delivery. Chats does not synthesize conversations. The owner supplied seven consumable identifiers and delegated two more. The ordered nine-tier catalog lives in Configuration/products.json. Entitlements and signing team are pending. On November 18, 2026 the owner confirmed com.roro.photography as the Bundle ID, replacing the earlier development identifier. Apple registration remains unverified.

## November 18 control correction

Home and Shorts now expand search inside their current top toolbar, with an independent creation icon. Closing clears query and keyboard without changing category; submitting dismisses the keyboard; returning from a child profile/detail restores search. Shorts stores search per route, and a newly opened video starts without an unrelated query. Pushed Shorts and personal profiles have a < return action.

App-owned actions use themed icons and accessible English names. Category/navigation labels, content titles and agreement hyperlinks remain readable. Member Follow/Message explicitly use icon plus text; Block uses only the owner's requested prohibition emoji. Blocking is device-local, atomically removes following, filters works/comments/collections and can be reversed in Settings. Conversation entries persist locally. Remote delivery requires a messaging service.
